# Family Trip Budget

A private, offline-first family trip budget tracker designed for GitHub Pages and iPhone Safari.

## Files
- `index.html`, `style.css`, `app.js`: app
- `manifest.json`, `service-worker.js`, `icons/`: PWA/offline support

## Publish with GitHub Pages
1. Download and unzip this folder.
2. Upload **all files and the `icons` folder contents** to the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Open the published Pages URL in Safari on iPhone. Tap Share → Add to Home Screen.

## Data and backup
- Records are stored in this browser on this device using localStorage.
- There is no login, cloud sync, or server database.
- Use **Download JSON backup** regularly. Restore a JSON backup on the same or another browser.
- CSV export can be opened in Excel.
- Clearing Safari website data can erase local app data. Back up before changing device/browser.

## Notes
- Starting trip: December Road Trip, 11–14 December 2026, RM1,650.
- Accommodation is excluded from the starting budget.
- Currency is MYR only.
- Shared expenses use editable percentages for Me and Husband (default 50:50).
- Arissa expenses are tracked separately and included in family totals.
- Complete trips manually to save their final report.
- This is a personal budgeting tool, not a bank or accounting system. Review settlement figures before transferring money.
